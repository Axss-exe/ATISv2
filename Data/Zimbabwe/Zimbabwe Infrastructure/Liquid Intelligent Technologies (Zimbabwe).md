# Liquid Intelligent Technologies (Zimbabwe)

**Infrastructure Type:**  Telecommunications Network
**Operational Status:** `operational`
**Operated By**: [[Liquid Intelligent Technologies]]
**Value Is**: The largest private fibre operator in Zimbabwe, part of a pan-African network spanning 110,000+ km. Its existence provides the only reliable high-bandwidth connectivity for mining operations requiring real-time monitoring, cloud services, and corporate VPNs. Without Liquid's fibre, mines would depend on congested satellite or microwave links with 10x higher latency and cost, preventing adoption of IoT, automation, and remote operations. The network runs along highways and railways, creating shared vulnerability with transport infrastructure.


## Summary

The largest private fibre operator in Zimbabwe, part of a pan-African network spanning 110,000+ km. Its existence provides the only reliable high-bandwidth connectivity for mining operations requiring real-time monitoring, cloud services, and corporate VPNs. Without Liquid's fibre, mines would depend on congested satellite or microwave links with 10x higher latency and cost, preventing adoption of IoT, automation, and remote operations. The network runs along highways and railways, creating shared vulnerability with transport infrastructure.

#### Technical Notes: 
Extensive fibre backbone; cross-border links to 5 countries
